## Portfolio Structure

### 1 Phishing Analysis
**Focus:** SOC email threat investigation & simulation  
**Labs:**
- **SOC Incident Investigation Lab** – Analyze phishing emails, endpoint behavior, network alerts; escalate True Positives.  
- **GoPhish Simulation & Email Auth Lab** – Test email delivery and authentication (SPF/DKIM/DMARC) across providers.  

**Tools:** Splunk SIEM, GoPhish, Kali Linux  
**Skills:** Phishing triage, campaign simulation, email headers & network correlation  

---

### 2 Network Traffic Analysis
**Focus:** Packet-level network investigation & threat detection  
**Labs:**
- **Wireshark Display Filter Playbook** – SOC reference for detecting port scans, brute force, exfiltration, web exploitation.  
- **DNS Traffic Analysis Lab** – Analyze DNS queries/responses, resolver behavior, network anomalies in a virtual lab.  

**Tools:** Wireshark, Kali Linux, VMware NAT, TCP/IP  
**Skills:** Packet triage, DNS analysis, detection logic, SOC playbook creation  

---

### 3 SOC Incident Response
**Focus:** Web exploitation detection, compromise analysis, mitigation  
**Labs:**
- **Blue Team Admin Portal Compromise** – Investigate authentication bypass, RCE, reverse shells, lateral movement.  
- **Incident Response Playbook Lab** – Triage alerts, document IOCs, map activity to MITRE ATT&CK.  

**Tools:** Splunk SIEM, firewall/WAF, endpoint monitoring  
**Skills:** Incident analysis, containment, recovery, alert correlation
